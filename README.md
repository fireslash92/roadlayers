# طبقات الطريق — أكتوبر العمران

نسخة التطبيق جاهزة لـ GitHub Pages، وتتضمن تعديل اسم الطبقة الثانية إلى «الطبقة اللاصقة الإسفلتية».

## التشغيل
فك الضغط وافتح index.html في متصفح حديث على الحاسب. ملفات التطبيق مكتفية ذاتيًا ولا تستخدم مكتبات أو خطوطًا من الإنترنت. لا تحتاج إلى تثبيت حزم أو قاعدة بيانات.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا باسم road-layers، ويمكن اختيار Public لاستخدام GitHub Pages المجاني.
2. فك الضغط وارفع محتويات الحزمة إلى جذر المستودع عبر Add file > Upload files. لا ترفع ملف ZIP نفسه، ولا تضع الملفات داخل مجلد إضافي.
3. تأكد أن index.html وapp.js متجاوران في الجذر، ثم احفظ عبر Commit changes.
4. افتح Settings > Pages.
5. ضمن Build and deployment اختر Source: Deploy from a branch.
6. اختر الفرع main والمجلد /(root)، ثم Save.
7. انتظر اكتمال النشر وافتح الرابط الذي يظهر في Pages.

الرابط المعتاد: https://USERNAME.github.io/road-layers/
مرجع GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## الاستخدام على شاشة المعرض
- السحب لتدوير المجسم، وإصبعان للتكبير والتصغير.
- اختيار الطبقة من المجسم أو القائمة لإظهار الشرح.
- تجميع الطبقات وتفكيكها، أو تشغيل جولة تلقائية.
- زر ملء الشاشة بحسب دعم المتصفح، ويمكن استخدام F11 على متصفحات الحاسب.
- جرّب اللمس وملء الشاشة على الجهاز الفعلي قبل المعرض.

## الملفات
- index.html: الواجهة والتنسيق العربي.
- app.js: المجسم والتفاعل وأسماء الطبقات والشرح.
- .nojekyll: ملف لإيقاف معالجة Jekyll.

## ملاحظات النموذج
الرسم ثلاثي الأبعاد محسوب برمجيًا ومعروض عبر Canvas 2D؛ لا توجد ملفات Blender أو GLB منفصلة في هذه النسخة. السماكات توضيحية وغير تنفيذية. طبقتا اللصق والتشريب ممثلتان بسماكة مبالغ فيها لتسهيل استكشافهما.
هذه نسخة تصدير مستقلة: تعديلات GitHub لا تتزامن تلقائيًا مع نسخة ChatGPT المنشورة.

## تحديث الواجهة الحكومية
واجهة بألوان أخضر داكن وذهبي وأبيض، واسم الوزارة والدائرة، وتذييل: جميع الحقوق محفوظة لدائرة الطرق بمحافظة البريمي 2026م. رمز الطريق زخرفي وليس شعارًا حكوميًا رسميًا.

## تعديل ألوان وسماكات الطبقات
الطبقة الثانية بنفس لون وسمك طبقة التشريب (الرابعة). طبقة الأساس الإسفلتية (الثالثة) بنفس لون الطبقة السطحية مع عدم وجود خطوط أو دهانات عليها.
